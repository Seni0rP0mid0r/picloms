# picloms — контентная карта v1

## Карта страниц

| Страница | Задача | Блоки | CTA |
| --- | --- | --- | --- |
| `/` | Передать образ бренда и направить в ассортимент | имиджевый скролл-нарратив; переход к каталогу; короткая подпись бренда; финальный переход | «Смотреть изделия» |
| `/catalog` | Спокойно выбрать вещь | заголовок; подтверждённые фильтры/категории; карточки товаров; пустое состояние | «Открыть изделие» |
| `/product/:slug` | Рассмотреть конкретную вещь и начать диалог | галерея; только подтверждённые поля; CTA/нейтральное состояние контакта; ссылка назад | «Написать в Telegram» |
| `/about` | Дать редакционный контекст бренда | текст бренда; подтверждённые материалы/съёмка при наличии | «Смотреть изделия» / Telegram |
| `/contacts` | Дать прямой способ связи | Telegram бренда; другие подтверждённые контакты; юридические ссылки при наличии | «Написать в Telegram» |

`/about` и `/contacts` не публикуются с вымышленным текстом: до поступления информации они остаются вне навигации. Literal `TBD` используется только в рабочих документах и не выводится посетителю.

## Главная: последовательность контента

1. Входной экран: логотип/знак и имиджевая фотография.
2. Скролл-сцены: фрагменты кампании, движение графического мотива и логотипа; смысл строится на изображениях, а не на неподтверждённых обещаниях.
3. Переход к изделиям: короткий навигационный блок без заявлений о коллекции, сезоне или наличии.
4. Финальный экран: повторный путь в каталог и в Telegram только после получения ссылки.

Анимация не должна быть единственным носителем информации: каждому экрану нужен статичный порядок чтения, а при reduced motion — отсутствие скролл-эффектов.

## Каталог и карточка товара

**Карточка в каталоге:** создаётся только для подтверждённого опубликованного товара с подтверждённой привязкой главного фото. Не выводить искусственные бейджи («new», «sold out», скидка) и фильтры без данных.

**Страница товара:**

- Галерея только из материалов, относящихся к конкретной вещи.
- Название, цена, варианты, размеры и наличие публикуются только после явного подтверждения.
- Технический ID записи передаётся в будущую заявку, но не обязан отображаться как коммерческий артикул.
- Состав, посадка, замеры, уход, сроки и условия не подтверждены; публично каждое такое поле скрывается.
- CTA «Написать в Telegram» появляется только для подтверждённого опубликованного товара с разрешённой заявкой. Сообщение содержит технический ID; подтверждённые название, вариант и URL существующей страницы добавляются по отдельности.
- Если Telegram не задан, CTA не имитирует работу и показывает нейтральное «Контакт бренда уточняется».

## Контентные сущности

| Сущность | Обязательные поля для запуска | Поля после подтверждения |
| --- | --- | --- |
| Товар (только подтверждённый) | технический ID, подтверждённое название, публичный slug, минимум одно фото с подтверждённой привязкой и web-правами, признак возможности заявки | категория, описание, цена, размеры, состав, уход, наличие, варианты |
| Кандидат товара | технический ID и исходное медиа | все коммерческие поля и подтверждение, необходимое для перевода в товар; публичный slug не создаётся |
| Изображение | технический ID, источник, роль и уверенность в роли, привязка к странице/товару, права использования | alt-текст, автор/кредиты, порядок показа |
| Контакт | Telegram URL или подтверждение, что он отсутствует | часы ответа, email, соцсети |
| Юридический документ | URL и статус публикации | название юрлица, реквизиты, политика, правила обработки данных |
