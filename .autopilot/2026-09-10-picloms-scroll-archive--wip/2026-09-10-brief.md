# Изначальная задача

> Записано 2026-09-10. Текст задачи не редактируется — он эталон, с которым сверяется готовый результат.

«Сделай но с моими фото и моим продуктом».

Пользователь передал подробный референс полноэкранной scroll-driven fashion/archive landing page: React 19 + TypeScript, Vite 6, Tailwind CSS v4, GSAP ScrollTrigger, Motion 12; две фазы — полноэкранный hero и поднимающаяся чёрная gallery-панель; desktop custom cursor; фиксированные logo/caption/navigation/product info; два видео с cursor scrubbing и dead zone; touch autoplay; responsive 2/3/4-column scattered grid из 10 изображений; RAF scale-in/scale-out карточек; outro с белой overlay, CTA `view` и footer; `prefers-reduced-motion`; breakpoint 640/1024. Все чужие `prmpt`-тексты, медиа и коммерческие данные заменить реальными материалами и продуктом пользователя.

Полное техническое описание в сообщении пользователя задаёт точные id и поведение: `scroll-spacer`, `main-canvas`, `outro-info`, `outro-buy`, `outro-overlay`, `outro-footer`, `.bp-card`; panel translate over first viewport, gallery translate after it, outro after `maxScroll`, dynamic spacer height, videos hidden after first viewport, symbol changes on scroll, overlay text uses exclusion blend.
